# Project 3: Spots

### Project Description

The Spots project is a site where users can upload their favourite images. The images can be enlarged and liked by the user.

**Technologies and Techniques used**
Semantic HTML5
CSS
Flat BEM
Flexbox
Responsive Grid
Media Queries
Figma created by designer
